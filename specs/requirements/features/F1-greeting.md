# Greeting

## Purpose

A visitor opens the page and sees a "Hi, World" greeting.

## User Stories

- F1.1 As a visitor, I open the page and see the greeting "Hi, World".
- F1.2 As a visitor, I can read the greeting without signing in.

## Decisions

- The greeting text is fixed and the same for every visitor.
- The page works on both desktop and mobile screens.

## Out of Scope

- Personalised greetings, language choice and any user input.
